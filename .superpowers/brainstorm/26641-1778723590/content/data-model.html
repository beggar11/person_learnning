数据模型

SQLite 表结构，FTS5 全文索引，双向链接关系

核心表

notes id, title, slug (唯一链接标识), content (Markdown), created_at, updated_at
links id, source_note_id, target_note_id（从 [[wiki-link]] 解析而来），created_at
tags id, name, slug
note_tags note_id, tag_id（多对多关联表）
notes_fts FTS5 虚拟表，索引 title + content，支持中文分词

关键设计决策

  1. links 表来自动解析——保存笔记时，后端正则提取 [[slug]]，自动维护 links 表。不需要用户手动建立链接。
  2. slug 唯一标识——笔记用 slug（URL 友好的简短标识）而非 ID 来引用。这样 [[machine-learning]] 可以直接解析到对应笔记，无论它在系统中的 ID 是什么。
  3. FTS5 支持中文——SQLite 原生的 FTS5 需要配合分词器（jieba 或 simple tokenizer）。保存时同步更新 FTS 索引。
