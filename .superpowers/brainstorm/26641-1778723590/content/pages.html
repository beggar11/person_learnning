页面结构

6 个页面，围绕笔记的创建、阅读、关联、发现

页面清单

/ 首页 / 笔记列表 最近更新的笔记列表，按时间/标签筛选，搜索入口
/note/{slug} 笔记详情 渲染后的 Markdown 内容，双向链接高亮，反向链接列表
/note/{slug}/edit 编辑笔记 Markdown 编辑器 + 实时预览，标签管理，保存时自动解析链接
/graph 知识图谱 力导向图，节点=笔记，边=链接，点击节点跳转笔记
/search?q= 搜索结果 FTS5 全文搜索，高亮匹配片段
/tag/{slug} 标签页面 该标签下的所有笔记列表
导航流示意
🔍 搜索框  |  笔记  |  图谱  |  + 新建
/ (首页)
▸ 笔记列表（卡片或表格）
▸ 按时间倒序
▸ 右侧标签云
▸ 点击 → /note/{slug}
/note/{slug} (详情)
▸ 渲染 Markdown
▸ [[链接]] 可点击
▸ 底部：反向链接
▸ 编辑按钮 → /note/{slug}/edit

路由设计

GET  /                    → 首页（笔记列表）
GET  /note/{slug}         → 笔记详情（渲染）
GET  /note/{slug}/edit    → 编辑页面
POST /api/notes           → 创建/更新笔记（JSON API）
GET  /api/notes           → 笔记列表（JSON，供搜索/筛选）
GET  /api/graph           → 图谱数据（节点+边 JSON）
GET  /search?q=...        → 搜索结果页
GET  /tag/{slug}          → 标签页
